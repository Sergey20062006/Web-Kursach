# Kpishka — Веб-додаток для нотаток

**Kpishka** — це простий та зручний веб-додаток для створення, редагування та організації особистих нотаток.  
Проєкт реалізований у вигляді віртуальної дошки зі стікерами, що дозволяє легко керувати ідеями, завданнями та списками справ.

## Основний функціонал

- **Авторизація користувачів**
  - Реєстрація та вхід
  - Паролі зберігаються у захищеному вигляді (bcrypt)

- **CRUD для нотаток**
  - Створення
  - Редагування (через модальне вікно)
  - Видалення

- **Чек-листи**
  - Створення списків завдань
  - Відмітка виконаних пунктів
  - Відображення прогресу

- **Папки**
  - Групування нотаток
  - Зручна навігація

- **Пошук**
  - Миттєвий пошук по заголовках нотаток

- **Архів (Soft Delete)**
  - Видалені нотатки не зникають одразу
  - Можна відновити або видалити назавжди

## Встановлення та запуск

### 1. Клонування репозиторію

### 2. Встановлення залежностей

``` BASH
npm install
```

### 3. Налаштування бази даних

- Створи базу даних у MySQL (наприклад: kpishka)
- Імпортуй файл: `database.sql`

### 4. Налаштування .env

- Створи файл .env у корені проєкту:

```
PORT=3000
DB_HOST=localhost
DB_USER=your_login
DB_PASSWORD=your_password
DB_NAME=kpishka
```

### 5. Запуск сервера

``` BASH
npm start
```

Після запуску відкрий у браузері: `http://localhost:3000`
